# HavaDurumuApp

Güncel hava durumu bilgilerini takip etmenizi sağlayan basit bir mobil uygulama.

Kullanıcılar girdikleri şehir bazlı anlık hava durumu verilerine ulaşabilir ve günlük tahminleri görüntüleyebilir. Uygulama hava durumunu takip etmeyi kolaylaştırır.

Favoriye eklediğiniz şehirlerin hava durumuna kolaylıkla bakabilirsiniz.
